# KATAL Team

The installable KATAL Team app, published with GitHub Pages: https://orwaaah.github.io/katal-team/

These files are built from the private `katal-crm` repository (`node pwa/build.mjs`), so don't edit
them here: change `Index.html` there, build, and copy the result into this repository.
Nothing private is in here: the key in the page is Supabase's public sign-in key, and all data
goes through the app's server, which checks who is signed in on every request.
